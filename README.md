# Bhanzu Math Quest (pre-class micro-experience)

Prototype for the Bhanzu Growth PM case study (Part 4). A parent opens this page from the booking WhatsApp; the parent answers 4 taps and gets a class checklist, the child plays a 3 level Math Quest whose 4th "Boss Level" only unlocks live in class, and a daily teaser keeps the class top of mind until the session. One tap confirm or reschedule turns silent no-shows into reschedules.

Single file, no build step, no backend (state is kept in the browser).

## Try it
Personalise with URL parameters:

```
?child=Aarav&parent=Priya&grade=4&teacher=Ms.%20Kavya&slot=2026-11-01T18:00
```

Add `&debug` to see the analytics events the page would send.
